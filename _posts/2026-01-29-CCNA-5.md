# Installing Cisco Packet Tracer on Ubuntu 24.04 LTS, Windows, and macOS

There are multiple tools that we can use for simulation of a Cisco network lab e.g. gns3, Cisco packet tracker. For a quick start, we will be using Cisco Packet Tracer, which is an essential tool for networking students and professionals. While Windows and macOS installations are generally straightforward, **Ubuntu 24.04 LTS** users face specific dependency challenges because newer Linux versions have phased out older libraries.

This guide provides a one-stop walkthrough for all three operating systems.

## 1. Ubuntu 24.04 LTS (The Linux Fix)

Ubuntu 24.04 has deprecated several legacy libraries (like libgl1-mesa-glx) that Packet Tracer still requires. To install it successfully, you must manually bridge these gaps.

### Step 1: Install Legacy Dependencies

Run the following commands in your terminal to fetch the necessary library from the 22.04 archives:

Bash

# Download the legacy library

wget http://mirrors.kernel.org/ubuntu/pool/universe/m/mesa/libgl1-mesa-glx\_23.0.4-0ubuntu1~22.04.1\_amd64.deb

# Install the downloaded package

sudo dpkg -i libgl1-mesa-glx\_23.0.4-0ubuntu1~22.04.1\_amd64.deb

# Install the cursor library (required for the GUI to launch)

sudo apt install libxcb-cursor0

### Step 2: Install Packet Tracer

Navigate to your Downloads folder and install the .deb package you downloaded from NetAcad:

Bash

sudo dpkg -i CiscoPacketTracer\_822\_Ubuntu\_64bit\_signed.deb

# Resolve any remaining broken dependencies

sudo apt-get install -f

## 2. Windows 10 & 11

The Windows installation is the most stable and handles its own dependencies automatically.

1. **Launch**: Double-click the .exe installer.
2. **Setup**: Follow the installation wizard. We recommend sticking to the default path: C:\Program Files\Cisco Packet Tracer.
3. **Finish**: Click Install. Once complete, launch the application.
4. **Authentication**: When prompted, select **Networking Academy** or **Skills For All** to sign in.

## 3. macOS (Intel and Apple Silicon)

Packet Tracer is compatible with both Intel Macs and M-series chips (M1/M2/M3) using Rosetta 2.

1. **Open DMG**: Double-click the .dmg file and run the .pkg installer inside.
2. **Security Gatekeeper**: If you see a "Developer cannot be verified" warning:
   * Go to **System Settings** > **Privacy & Security**.
   * Scroll down and click **"Open Anyway"**.
3. **Application**: Once installed, you will find it in your **Applications** folder.

## Summary Cheat Sheet

| **Platform** | **Format** | **Key Requirement** |
| --- | --- | --- |
| **Ubuntu 24.04** | .deb | Manual install of libgl1-mesa-glx |
| **Windows 10/11** | .exe | Standard Admin privileges |
| **macOS** | .dmg | Privacy & Security permission |

### Troubleshooting

* **Login Loop:** If the login window keeps popping up, ensure your default web browser is updated. Packet Tracer uses the browser for OAuth.
* **No Icon on Linux:** If the application doesn't show in your app drawer, try launching it via terminal with the command packettracer.
