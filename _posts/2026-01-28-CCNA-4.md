# Understanding Network Addressing: MAC vs. IP

In modern networking, data packets find their way to the correct destination using a layered addressing system. This post breaks down the fundamental differences between hardware-based **MAC Addressing** and software-based **IP Addressing**.

---

## 1. MAC Addressing (Layer 2)

A **Media Access Control (MAC)** address is the permanent, physical identity of your network hardware. Unlike an IP address, which changes depending on where you connect, the MAC address is "burned into" the device at the factory. It operates at **Layer 2 (Data Link Layer)** of the OSI model and is used to deliver data between devices on the same local segment.

### The Many Names of MAC
Because it is tied directly to the hardware, you will often hear it referred to as:
1. Physical Address
2. Hardware Address
3. Burn-In Address (BIA)
4. Ethernet Address
5. Layer 2 Address

### Structure of a MAC Address
A MAC address is **48 bits** long, represented by 12 hexadecimal characters.
* **Vendor Code (OUI):** The first 24 bits identify the manufacturer (e.g., Cisco, Dell, Intel).
* **Serial Number:** The last 24 bits are a unique identifier for that specific network card.



---

## 2. IP Addressing (Layer 3)

While the MAC address identifies the "who," the **Internet Protocol (IP)** address identifies the "where." It is a logical address that allows data to be routed across different networks and the internet. It operates at **Layer 3 (Network Layer)**.

### Binary vs. Decimal
Computers process data in **Binary** (0s and 1s), but humans use **Dotted Decimal** to make addresses easier to read. An IPv4 address is **32 bits** long, divided into four 8-bit sections called **octets**.

### The Math of an Octet
Each bit in an octet has a specific value based on its position ($2^0$ through $2^7$):

| 128 | 64 | 32 | 16 | 8 | 4 | 2 | 1 |
| :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: |

* **Minimum Value:** 0 (all bits off)
* **Maximum Value:** 255 (all bits on)

---

## 3. Classification of IP Addressing

To organize the massive number of devices on the internet, IP addresses are categorized into **Classes**. This system determines how many bits are used for the **Network ID** (the neighborhood) versus the **Host ID** (the specific house).

| Class | Range | Primary Usage | Default Subnet Mask |
| :---: | :--- | :--- | :--- |
| **A** | 1 – 126 | Huge networks (Corporations) | 255.0.0.0 |
| **B** | 128 – 191 | Medium to large networks | 255.255.0.0 |
| **C** | 192 – 223 | Small networks (Home/Small Biz) | 255.255.255.0 |
| **D** | 224 – 239 | Multicasting (Video streams) | N/A |
| **E** | 240 – 255 | Experimental / Research | N/A |



> **Pro Tip:** If you see an address starting with `127`, it is reserved for **Loopback** testing (your own machine) and is not used for standard network communication.
